# 切换微信账号与重新连接

在“首次配置”或“连接设置”中重新识别目录，明确选择目标账号，再点击“一键连接并验证”。账号目录、其父目录及 `db_storage` 会归一为同一账号，不因目录写法不同丢失已保存的凭据。

连接分为数据库验证和实时微信核对。已有密钥能读取旧数据库，不等于当前微信登录了这个账号。保存前会确认匹配微信已就绪、只打开目标账号的数据库；停止旧服务后还会再检查一次，避免核对期间用户又换号。

- 尚未登录或组件正在加载时，程序限时等待。请完成目标账号登录并等待同步。
- 提示 `HOOK_ACCOUNT_MISMATCH` 时，当前账号与所选目录不一致；先重新选择实际账号或切换微信，再重试。
- 提示 `HOOK_MULTIPLE_ACCOUNT_DATABASES` 时，微信进程同时打开了多个账号的数据库。点击“修复微信连接”，核对匹配微信进程，经再次确认后停止并重开，然后登录目标账号并重新连接。
- 提示元数据、令牌或版本异常时，不继续切换，不放宽账号校验。

修复入口只处理已核对的匹配客户端，不自动结束其他安装实例或系统进程，也不自动切换或登录账号。失败保留原账号配置；如果旧服务已停止，可在对应账号重新登录后重试。

切换成功后，各账号恢复自己的聊天范围和状态。请从托盘完整退出并重开 DSH，再启动助手；DSH 的账号隔离检查继续保留。验证成功后若又手动换号，需要重新连接，发送端仍会逐次检查账号，拒绝向不匹配的账号发送。

操作记录会显示失败阶段和错误码，不包含密钥或本机连接令牌。专项验证命令：`npm run test:wechat-account`，使用临时目录和模拟客户端，不向真实微信发送消息。
