# 安装位置与数据迁移

安装时只需选择一次根目录：程序自动放入 `app`，WeChatAgent 的数据自动放入同级 `data`，不再要求第二次选择数据文件夹。程序与数据目录保持分离；卸载只删除程序目录，默认保留数据。

例如选择 `D:\WeChatAgent`：

```
D:\WeChatAgent\app\WeChatAgent.exe
D:\WeChatAgent\data\workspace\
D:\WeChatAgent\data\runtimes\
D:\WeChatAgent\data\desktop\
```

`workspace` 保存配置、人设、表情包、群友记忆、群聊关联、聊天缓冲、消息处理进度与发送回执。`runtimes` 保存内置运行环境。`desktop` 保存界面设置和缓存。DSH 需要单独安装，其数据由 DSH 管理；旧版本迁移留下的 `dsh` 目录会保留。

同一安装位置升级会沿用已有数据路径，包括旧版本单独指定的文件夹。选择新的安装根目录时，目标数据位置自动设为新根目录下的 `data`，并检测之前记住的数据位置或旧版 `%APPDATA%\WeChatAgent`。需要迁移时，首次启动会显示来源和目标，安装期间不复制或删除旧数据。确认后会按进程归属停止旧实例管理的后台服务；匹配微信、DSH 和旧版窗口仍需从托盘退出。程序会核对运行进程、复制用户数据、逐文件校验，再切换到新位置；原副本不会自动删除。停止操作使用新版本自带的进程归属检查，不执行旧备份中的代码。

迁移包含账号凭据、人设、聊天范围、表情池、群友记忆、会话映射和发送回执。不会搬动微信原始聊天数据库，也不复制旧版 Node/Python 运行环境或正在使用的进程 PID。旧版内置 DSH 的会话与附件按原始字节复制，不编辑压缩的历史日志。外部 DSH 仅更新指向旧 WeChatAgent 的插件路径，并备份原配置。

复制失败、源数据仍在变化、目标已有未确认数据或发现不安全的目录联接时，会停止迁移并保留来源。不要手动合并两个账号的数据目录。迁移中断留下的 `.migration-*` 文件夹和锁文件应先核对，原数据仍在旧位置。

同一路径升级会复用数据目录，不会重新导入旧副本。`app\storage.ini` 记录数据位置，`data\.wechatagent-data.json` 与 `data\backups\migration.json` 记录迁移结果。确认正常运行后，旧副本和不用的旧版运行环境可以另行清理。

同一电脑、同一 Windows 用户内迁移会保留受保护的凭据；跨电脑或跨 Windows 用户仍需重新连接微信。旧 installer 不包含新布局，不能用旧版覆盖新的 `app` 安装路径来迁移数据。

历史修复备份中的 `dsh/dsh-social-bridge-plugin.original-link` 若指向旧开发插件目录，会保留为 `backups/migration-link-references-*.json` 中的引用记录，不复制目标内容，也不重新创建外部联接。迁移报告记录引用数量和清单位置；原备份联接保持不变。其他未支持的联接仍停止迁移，并显示具体路径。
