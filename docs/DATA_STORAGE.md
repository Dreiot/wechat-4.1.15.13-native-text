# 安装位置与数据迁移

新安装器将程序放入所选目录下的 `app`，默认将数据放入同级 `data`。也可以在“选择数据位置”页面单独指定数据文件夹。程序与数据目录不能互相包含；卸载只删除程序目录，默认保留数据。

例如选择 `D:\WeChatAgent`：

```
D:\WeChatAgent\app\WeChatAgent.exe
D:\WeChatAgent\data\workspace\
D:\WeChatAgent\data\runtimes\
D:\WeChatAgent\data\desktop\
D:\WeChatAgent\data\dsh\
```

`workspace` 保存配置、人设、表情包、群友记忆、群聊关联、聊天缓冲、消息处理进度与发送回执。`runtimes` 保存内置运行环境。`desktop` 保存界面设置和缓存。由程序启动的内置 DSH 使用 `dsh`；独立安装的 DSH 保留自己的数据位置。

安装器检测之前记住的数据位置，旧版本则检测 `%APPDATA%\WeChatAgent`。勾选迁移后，首次启动会再次显示来源和目标。确认后会按进程归属停止旧实例管理的后台服务；匹配微信、DSH 和旧版窗口仍需从托盘退出。程序会核对运行进程、复制用户数据、逐文件校验，再切换到新位置；原副本不会自动删除。停止操作使用新版本自带的进程归属检查，不执行旧备份中的代码。

迁移包含账号凭据、人设、聊天范围、表情池、群友记忆、会话映射和发送回执。不会搬动微信原始聊天数据库，也不复制旧版 Node/Python 运行环境或正在使用的进程 PID。内置 DSH 的会话与附件按原始字节复制，不编辑压缩的历史日志。外部 DSH 仅更新指向旧 WeChatAgent 的插件路径，并备份原配置。

复制失败、源数据仍在变化、目标已有未确认数据或发现不安全的目录联接时，会停止迁移并保留来源。不要手动合并两个账号的数据目录。迁移中断留下的 `.migration-*` 文件夹和锁文件应先核对，原数据仍在旧位置。

同一路径升级会复用数据目录，不会重新导入旧副本。`app\storage.ini` 记录数据位置，`data\.wechatagent-data.json` 与 `data\backups\migration.json` 记录迁移结果。确认正常运行后，旧副本和不用的旧版运行环境可以另行清理。

同一电脑、同一 Windows 用户内迁移会保留受保护的凭据；跨电脑或跨 Windows 用户仍需重新连接微信。旧 installer 不包含新布局，不能用旧版覆盖新的 `app` 安装路径来迁移数据。
