# 退出与后台服务

- 点击窗口右上角「×」仍收起到托盘，机器人继续运行。
- 点击侧栏或托盘的「退出应用」时，先停止本安装实例管理的读取器、OneBot 和消息桥接服务，再关闭窗口、托盘与本机控制台。依赖这些服务的自动回复、主动聊天、上下文维护及表情发送队列随之停止。
- 微信和外部 DSH 是独立程序，保持运行。DSH 中与本项目无关的任务不受影响；正在进行的机器人请求会随桥接连接关闭而取消。

退出前仍会处理未保存设置；选择继续编辑不会停止服务。配置准备、连接账号等操作正在进行时，需等待操作结束后退出。退出清理期间禁止启动新服务或保存设置，重复点击退出共用同一次清理。

停止进程前核对记录中的程序路径、命令标记及当前项目目录。其他安装实例、外部程序和已被复用的 PID 不会被当作本实例停止；过期或外来记录只从当前实例清除。一个服务停止失败时会继续尝试其余服务，保留失败项记录，显示错误并保留应用窗口供重试。

退出日志位于当前工作区 `state/logs/shutdown.log`。正常退出后移除属于本桌面进程的控制台运行记录。用户配置、聊天状态、人格、表情和群友记忆均保留；再次打开应用后可重新启动服务。

本机制处理正常退出。任务管理器强制结束、进程崩溃或突然断电无法保证执行退出流程。
