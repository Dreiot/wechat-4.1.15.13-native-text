# Windows 安装发行版

安装器为 WeChatAgent-Setup-0.3.9-x64.exe，适用 Windows 10/11 x64。包含独立桌面应用、Node.js、Python、读取依赖及维护者已授权的微信、发送与自动连接组件。匹配微信 4.1.10.27，DSH 桌面程序需单独安装，首次配置提供官方下载链接；项目插件 SDK 验证版本为 0.2.0-rc.2。

## 安装位置与首次使用

当前用户级安装，只需选择一次安装根目录。程序自动放入 app 子目录，WeChatAgent 数据自动放入同级 data，不再出现单独的数据目录选择页。相同安装位置升级沿用旧数据路径；更换根目录时，首次启动确认后迁移到新的 data。建议预留至少 6 GiB；迁移保留旧副本时需额外空间。

首次启动若检测到旧数据，会显示来源和目标，经确认后复制并校验，再切换到新位置。请先从托盘退出旧版窗口、DSH 和匹配微信；由旧实例管理的后台服务按进程身份检查后停止。原数据不会自动删除，微信原始数据库不搬动，外部 DSH 保留自己的数据位置。详见 [数据位置与迁移](DATA_STORAGE.md)。

新用户打开匹配微信，点击“自动查找账号”，选择当前账号，再点击“一键连接并验证”。程序先验证已有读取凭据，缺失或失效时自动获取；获取期间需要在微信完成登录。验证通过后才使用当前 Windows 用户的 DPAPI 保护并保存，失败保留原配置。随后通过引导链接单独安装或选择已有 DSH，登录并启用本机插件、选择允许的聊天，再启动助手。首次聊天范围为空。

微信窗口已打开而发送组件未就绪时，可使用首次配置或工具页的匹配微信恢复入口，核对进程后经二次确认停止并重新打开。详见 [微信启动恢复](HOOK_STARTUP_RECOVERY.md)。

## 升级与退出

升级到 0.3.9 前，停止助手服务并完整退出旧版 WeChatAgent、DSH 和匹配微信。安装时选择根目录，首次启动确认迁移来源和目标后重新登录、加载插件并启动服务。相同数据位置的后续升级保留已有配置、人格编辑、表情池及私有状态。

点击窗口“×”收起到托盘；点击“退出应用”先停止本实例后台服务，停止失败则保留窗口供重试。微信及外部 DSH 不随该退出操作被关闭。卸载默认保留独立数据目录。详见 [退出与后台服务](EXIT_SHUTDOWN.md)。

## 源码与构建

此源码副本不包含安装器、vendor 程序、账号或聊天数据。安装器、SHA256SUMS.txt 与 VERIFICATION.json 作为 GitHub Releases 附件单独上传；release/、state/、运行环境及第三方二进制排除在 Git 源码提交外。

从根 package.json 安装构建依赖。维护者需准备已授权的匹配微信、Hook 编译产物及 components/weflow-cli/resources/key/win32/x64/wx_key.dll。无需准备 DSH 程序或设置 WECHATAGENT_DSH_SOURCE；构建只校验插件 SDK，发行清单标记 dshBundled=false，并保留第三方许可。

```powershell
npm run desktop:build
npm run installer:runtime
npm run installer:build
npm run privacy:check
```

本版包含 DSH 工作区分组、单次目录选择、旧数据迁移、退出清理、新版 Hook 和恢复入口，并保留表情包管理、群聊重新关联、扩展卡片、媒体任务隔离及会话历史恢复。具体构建号、安装器校验值、回归及解包验证结果，以 Release 附件 VERIFICATION.json 为准。
