# 回复协议标记处理

`RESPOND:` 是模型与发送桥接之间的控制标记，发送到微信的正文不应包含这个前缀。

- 解析器在分条前清理明确的行首标记，兼容大小写、中文冒号、重复包裹和每段重复标记。
- 正常英文用法、句中提及、行内代码、引用和完整代码示例保持原样；代码示例保持为同一条消息。
- 无法确认的格式只尝试一次模型校正。仍然无效时不发送，不放宽思考内容或表情引用校验。
- 重启后遇到旧待发草稿中的协议标记时，取消剩余投递并记录状态说明，继续处理新消息。已确认发送的历史和发送操作编号不改写，也不自动重发。

源码更新后重启 WeChatAgent 后台服务生效，无需删除 DSH 会话、人设或消息记录。已发送到微信的历史消息不会被改动。

隔离回归验证：`npm run test:reply-protocol`。测试使用临时目录和模拟发送器，不向微信发送消息。
